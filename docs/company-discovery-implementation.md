# Company discovery retirement

The old Node definitions, Blocks, Process plans, bundled worker, qualification
owner, rebuild scripts, execution commands, MCP tools and preserving tests are
removed. They are not active reusable capabilities.

Discovery must be rebuilt through current shared-type Forge/Atlas authoring
and Rynth installed workers. Declare shared fields once. Rynth owns the outer
DAG; each inner worker owns its DAG and event custody.

The remaining Python CLI only inspects and exports retained records. It cannot
rebuild or execute a discovery worker.
